# Standup Profile

Use this profile for a copy-ready, one-minute update for product and company readers. Match the
user's language.

## Window and selection

Review yesterday by default; on Monday, review Friday through Sunday. Honor an explicit window. Keep
the three strongest completed business chains. Let a substantial production repair
stand alone when its business meaning differs from the prevention work.

Each completed bullet leads with the concrete result, then why it mattered, the contributor's direct
action, concise proof, and quiet tracker or review anchors.

Use `需要幫忙事項` only for a real external blocker, decision, or review dependency. Put remaining
work under `今日重點` as at most three business gates with observable completion conditions.

## Output

For Traditional Chinese, use:

```text
✅ 昨日交付
- {最多三個完成結果；包含 why、直接貢獻與精簡證據}

🙋 需要幫忙事項
- {真實外部 blocker 或「（無）」}

🎯 今日重點
- {最多三個下一個商業關卡與完成條件}
```

Use equivalent labels and an explicit none marker in other languages.

Return exactly one fenced block. When there is no relevant business activity, say the team can skip
the update. Keep implementation vocabulary, ratings, self-promotion, and unsupported claims out of
the output. Return inline; create a file only when the user requests one.

## Acceptance

- The update can be read aloud in one minute.
- Completed outcomes dominate and appear only under `昨日交付`.
- Every blocker requires an external action; ordinary remaining work stays under `今日重點`.
